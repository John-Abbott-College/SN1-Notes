# Final Exam Study Guide

This page has notes for effective studying for the Fall 2025 final exam.

## Final Exam Topics

Using the SN1 notes website as reference, the following items are _not_ included in your final exam:

- Getting Started & Introduction sections
- Type hinting
- Scientific notation
- Splitting & slicing strings
- Only basic f-string formatting required
- Reading/writing files (input/output/.csv files)
- External libraries (matplotlib, numpy, Turtle)

That means, everything else on this website _could be_ included in your final exam.

## Reference sheet

A reference sheet will be given during the exam. A draft version of it is available here: [Fall 2025 Exam Reference sheet](https://john-abbott-college.github.io/SN1-Notes/Files/final-exam-reference-sheet.pdf)

Make sure you understand all of the commands and operations inside of that sheet.
