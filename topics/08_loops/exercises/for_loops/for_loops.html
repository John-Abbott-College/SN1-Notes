Tracing Loops

What will be the output of this program?

grade = 78
for _ in range(10):
    grade += 1

print(grade)

Note: it’s actually legal to name a variable as just an underscore _ like this and the convention is that we do this when we have to create a variable but we have no intention of actually using the variable.
