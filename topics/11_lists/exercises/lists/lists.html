Some Cool Grades

  • Prompt the user how many grades they want to enter
  • Prompt the user for the grades, one at a time
  • Store all the grades in a single list
  • print the list

Note: we cannot use “input” in the web browser so you must do this in Thonny

NoteHint

How do you prompt the user with python?

TipSolution

We can’t run code that uses input in the web browser, so run this in Thonny:

grades = []
num = int(input("How many grades do you want to enter? "))

for i in range(num):
    grade = float(input(f"Enter grade for student {i + 1}: "))
    grades.append(grade)

print(grades)
