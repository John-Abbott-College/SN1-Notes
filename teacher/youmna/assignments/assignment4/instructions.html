Explanation of the starter code

In assignment4.py you are given parallel lists for elements 1 (H) to 54 (Xe) of the periodic table. The value at index i of every list describes the same element:

List Contents
ELEMENTS element symbol, e.g. 'Ne'
ION_ENERGIES first ionization energy (eV): energy needed to remove one electron
RADII covalent radius (pm)

You are also given three lists of symbols only: NOBLE_GASES, ALKALI_METALS, HALOGENS.

These lists are all constants so you should NOT modify these lists anywhere in your program, but you can read these lists from within any function you write.

⚠️ Restrictions

Throughout this assignment when you’re working with lists you may use: append, insert, for, if/elif/else, in, not in, index, enumerate, zip, sum, range and len. You may not use list comprehensions, generator expressions, map(), filter(), lambda, dictionaries, sets, max(), min(), pandas, or NumPy. If you’re unsure whether you’re allowed to use something else then ask me.

The index() function

For some parts of this assignment you will need to find information in one list and then use the index (aka position) of what you found to get information from the same index in another list. You are capable of writing a for loop to check one-by-one through a list to look for a certain value but you can instead use this list method from Python: Notes on the index() function

Question1: Ionization Energy

Write a function ionization_energy()

Input parameters:

  • element which will be the symbol of an element (e.g. ‘O’ for oxygen)

Returns: ionization energy from ION_ENERGIES for the specified element. If no energy is found for that element (e.g. if the element was not valid) then return None.

Test your function in main()

In main(), use your function ionization_energy() to get the first ionization energy of iron ('Fe') and print it with a label and units. You can choose how to label it.

Expected result:

`Fe` ionized energy:  7.9 eV

Test your function in main()

In main(), use your function radius() to get the covalent radius of bromine ('Br'), and print it with a label and units. You can choose how to label it.

Write a function group_energy()

Input parameters:

  • group which will be a list of element symbols

Test your function in main()

In main(), use your function group_energy() with the list of elements of your choice. Make sure it’s correctly calculating the average.

PART 2

To plot data on a line or scatter plot you will need lists that contain the data points. One list will hold all of the values for the horizontal axis (e.g. x) and one for the vertical axis (e.g. y). Given these two lists of values we can plot them easily like:

plt.plot(x_values1, y_values1, color="red", label="series 1")

or:

plt.scatter(x_values2, y_values2, color="red", label="series 2")

plt.plot will draw a line chart and plt.scatter will draw a scatter (just the dots).

You can choose different colours for each of the groups or data series you are printing, and assign a label for each.

There are many other options you can specify also including the line thickness, which shape of “dots” etc.

After all of your calls to plt.plot and/or plt.scatter, make one call to plt.show() to make the graph appear on screen.

Before you can use these functions, you must import the plotting library by adding this at the top of the file: import matplotlib.pyplot as plt

Question 6: Energy vs Radius

Write a function energy_vs_radius()

Create a function named energy_vs_radius() that takes:

Input parameters:

  • ungrouped: this will receive the list you created in ungrouped_elements()
  • filename: this is string specifying the name of the file under which the graph will be saved. Use ""energy_vs_radius.png" as a default value.
  • show_graph: this is a Boolean which determines if the graph should be displayed on the screen.

Returns:

This function should not return anything.

Task:

Now, you have four lists of elements (the three original ones, plus one you have created for the “ungrouped” which is passed as a parameter to this function).

For each of the 4 groups you need to make lists to hold their energies and their radii. There are many ways to do this. You might choose to use zip() or enumerate(), or an indexed for loop. You might also want to use the in keyword as part of this.

Once you’ve made the two lists for a group, add a call like: plt.scatter(radii, energies, color="purple", label="Noble Gases")

  • Make four calls to plt.scatter with radii on the X axis and energies on the Y axis. Use different colours and labels for each group.

  • Add a title, axis labels with units and a legend to your graph using: plt.title, plt.xlabel, plt.ylabel and plt.legend

See this reference page for help: https://www.w3schools.com/python/matplotlib_labels.asp

  • At the end of energy_vs_radius(), add these lines to save the graph and optionally show it on the screen.

    plt.savefig(filename)

if show_graph:
  plt.show()

plt.close()
